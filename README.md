# Органайзер особистого часу

Вебзастосунок для планування задач, ведення календаря та аналізу виконання.
Рекомендаційна математична модель поєднує важливість, терміновість і історію
виконання задач з урахуванням давності спостережень.

## Можливості

- Реєстрація та вхід, окремі дані кожного користувача.
- Створення, редагування й архівування задач із категорією, важливістю,
  тривалістю, найранішим початком і граничним строком.
- Тижневий календар із подіями, перервами та перевіркою перетинів.
- Автоматичне бронювання часу після збереження задачі з указаним початком.
- Формування рекомендованого плану та його прийняття до календаря.
- Фіксація початку й завершення роботи, аналітика планового та фактичного часу.

## Технології

Python 3.13, Flask, SQLAlchemy, SQLite, Flask-Login, Flask-WTF,
HTML, CSS і JavaScript. Інтерфейс українською мовою.

## Локальний запуск у Windows

Потрібні Python 3.13 і Git. Виконайте в PowerShell:

```powershell
git clone https://github.com/EmrJeck/personal_time_organizer.git
cd personal_time_organizer
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\.venv\Scripts\python.exe create_db.py
.\.venv\Scripts\python.exe run.py
```

Відкрийте http://127.0.0.1:5001 і зареєструйте власний обліковий запис.
Для наступних запусків можна використовувати `start.cmd`.
У PyCharm виберіть створене середовище `.venv` як інтерпретатор і запускайте `run.py`.

База та локальний ключ сесій створюються в `instance/` і не входять до репозиторію.
Ключ можна задати змінною середовища `ORGANIZER_SECRET_KEY`.
Надсилання електронних листів вимкнено. `run.py` запускає локальний сервер;
інструкція не описує розгортання сервісу для публічного доступу.

## Використання

1. Створіть задачу, задайте її важливість, тривалість і часові обмеження.
2. Укажіть майбутній початок для автоматичного розміщення або скористайтеся календарем.
3. На сторінці рекомендацій виберіть період і доступні години, сформуйте та прийміть план.
4. Позначайте початок і завершення роботи, щоб накопичувати історію для аналітики.

Календар використовує крок 15 хвилин; тривалість округлюється вгору.
За конфлікту з подією чи граничним строком система повідомляє про помилку.
Фактичний час визначається за діями користувача, а не автоматичним спостереженням.

## Перевірка

Із кореня проєкту після встановлення залежностей:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -p "test_*.py"
```

Тести використовують тимчасові бази й синтетичні облікові записи.

а не вимірювання продуктивності реальних користувачів.

| `tests/` | Автоматизовані перевірки й локальні демонстрації |
| `experiments/` | Відтворювані симуляції та результати порівняння |
| `docs/` | Технічна документація та графіки |
